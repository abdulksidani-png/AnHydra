# data/

Raw and processed data lives here. **Nothing in this folder is committed** (see `.gitignore`) — it's
all regenerated by `python -m tardiscreen.data`.

Expected files after the pipeline runs:

| File | Made by | What |
| --- | --- | --- |
| `dataset.csv` | `data.py` | labeled sequences + `cluster_id` |
| `sequences.fasta` / `*.clstr` | `data.py` (CD-HIT) | clustering inputs/outputs |
| `embeddings.npy` | `embed.py` | cached ESM-2 vectors |
| `results_table.csv`, `*.png` | `evaluate.py` | the eval table + plots for the README |

See `docs/METHODS.md` for sources and the cluster-split rule.
