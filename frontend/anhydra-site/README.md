# AnHydra — site

The AnHydra website as built in Duda Vibe, copied out of the Duda editor into this repository: a scroll-driven
landing page, the sequence screener, and the about page. React 19, TanStack Router (file-based routes) and
Tailwind CSS 4, built with Vite as a static single-page app.

```
npm ci
npm test
npm run dev          # http://localhost:5173
```

`npm run dev` proxies `/score`, `/health`, `/me` and `/ready` to `http://127.0.0.1:8000`. Set
`VITE_PROXY_TARGET` in `.env.local` to use another backend. Start the backend from the repository root:

```
python -m uvicorn app.main:app --env-file .env --host 127.0.0.1 --port 8000
```

## Layout

```
src/
├── routes/          one file per page (/, /screen, /about); __root.tsx wraps them in the top bar
├── components/      Landing, Result (dial, residue map, drivers), Evidence (neighbour map, AlphaFold
│                    backbone), Ensemble, Orbit (shared 3D canvas controls), Tour, Layout
├── lib/protein.ts   API client, residue classes, motif scan, feature labels, AlphaFold loader
├── lib/demo.ts      sample results for the three example chips, clearly flagged as demo output
├── config/settings.json   per-page titles and descriptions
├── data/team.ts     team members and the "built with" list
├── anhydra.css      the site's styles
└── styles.css, theme.css  Tailwind setup and theme tokens
```

`src/routeTree.gen.ts` is generated by the TanStack Router plugin whenever Vite runs; it is committed so
`tsc` works on a fresh checkout.

## What differs from the Duda project

- Duda hosts the site with TanStack Start. Here it is a plain Vite SPA, so `main.tsx`, `routes/__root.tsx`,
  `index.html` and the build config were written for this repo.
- Duda's `/sitemap.xml` server route needs Duda's host, so it is replaced by a static `public/sitemap.xml`.
- The landing-page photo still loads from Duda's CDN (`irp.cdn-website.com`, see `components/Backdrop.tsx`).

## Deploying

`npm run build`, then have Caddy serve `dist/` with a fallback to `index.html` for client-side routes, and proxy
`/score`, `/health`, `/me` and `/ready` to uvicorn.
